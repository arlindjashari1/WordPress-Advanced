## 🚀 Quick Setup (2 Minutes)

### Step 1: Go to WordPress Dashboard
1. Open your WordPress admin panel
2. Login with your admin account

### Step 2: Create Food Categories
1. Click: **Menu Items** → **Food Categories** (in left sidebar)
2. Click: **+ Add New Category**
3. Create these categories (copy & paste the names):
   - **Appetizers**
   - **Main Courses**
   - **Desserts**
   - **Beverages**

Each time, enter the name and click **Add New Food Category**

### Step 3: Add Sample Food Items
1. Click: **Menu Items** → **+ Add New**
2. Copy and paste each item below:

### Step 4: Create Menu Page
1. Click: **Pages** → **+ Add New**
2. **Title**: Our Menu (or whatever you want)
3. On the right side, find: **Template** dropdown
4. Select: **Restaurant Menu**
5. Click: **Publish**

### Step 5: View Your Menu in Chrome
1. Click the **View Page** button
2. Open in Chrome browser
3. You should see:
   - ✅ Food photos
   - ✅ Prices
   - ✅ Items organized by category
   - ✅ Beautiful responsive design

## 📸 How to Add Images in WordPress

1. In Menu Items → Add New
2. Click: **Add Featured Image** button
3. Click: **Upload Files**
4. Choose image from your computer
5. Click: **Set as featured image**
6. Done!

## ✨ Customization Tips

### Change Colors
1. Go to: **Appearance** → **Customize**
2. Find: **Restaurant Colors**
3. Change the gold color to your brand color
4. Save!

### Add Restaurant Info
1. Go to: **Appearance** → **Customize**
2. Find: **Contact Information**
3. Add your:
   - Phone number
   - Email
   - Address
   - Operating Hours
4. This appears in footer automatically!

## 🐛 Troubleshooting

### I don't see the menu page?
- ✓ Did you create at least 1 Food Category?
- ✓ Did you add at least 1 Menu Item?
- ✓ Did you select "Restaurant Menu" template for the page?
- ✓ Try refreshing (Ctrl+F5)

### Images not showing?
- ✓ Did you upload featured images?
- ✓ Try uploading smaller images (max 2MB)
- ✓ Clear cache (Ctrl+Shift+Delete)

### Prices not showing?
- ✓ Make sure you filled the Price field
- ✓ Price must be a number (e.g., 9.99)
- ✓ Save the item after adding price

### Chrome shows blank page?
- ✓ Check WordPress Console for errors
- ✓ Try a different browser
- ✓ Check if menu items are published

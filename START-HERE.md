## 🚀 How to Get It Working in Chrome Right Now

### 5-Minute Quick Start:

**Step 1:** Go to WordPress Admin Dashboard

**Step 2:** Create Food Categories
- Click: **Menu Items** → **Food Categories**
- Add: Appetizers, Main Courses, Desserts, Beverages

**Step 3:** Add Menu Items with Photos and Prices
- Click: **Menu Items** → **Add New**
- **Title**: Name of dish
- **Upload Image**: Click "Add Featured Image" → upload food photo
- **Excerpt**: Short description
- **Price**: Add in "Price" box at bottom
- **Ingredients**: Add in "Ingredients" box
- **Category**: Select which category
- Click: **Publish**

**Step 4:** Create Menu Page
- Click: **Pages** → **Add New**
- **Title**: "Our Menu"
- Right side → **Template**: Select "Restaurant Menu"
- Click: **Publish**

**Step 5:** View in Chrome
- Click: **View Page**
- See your beautiful menu with photos and prices! ✅

### Common Questions

**Q: How do I add an image to a menu item?**
A: Click "Add Featured Image" when editing the item

A: Scroll to bottom of edit page, find "Price" box

**Q: How do I change the gold color?**
A: Appearance → Customize → Restaurant Colors

**Q: I don't see my menu on the page?**
A: Make sure the page template is set to "Restaurant Menu"

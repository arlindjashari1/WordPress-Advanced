🚀 HOW TO GET IT WORKING IN CHROME - 5 MINUTES
==============================================

Step 1: Go to WordPress Admin Dashboard

Step 2: Create Food Categories
   - Menu Items → Food Categories → Add New
   - Create: Appetizers, Main Courses, Desserts, Beverages

Step 3: Add Menu Items with Photos & Prices
   - Menu Items → Add New
   - Title: (e.g., "Grilled Salmon")
   - Featured Image: Upload food photo
   - Excerpt: Short description
   - Price: Enter price (e.g., 24.99)
   - Ingredients: List ingredients
   - Category: Select food category
   - Publish

Step 4: Create Menu Page
   - Pages → Add New
   - Title: "Our Menu" (or your choice)
   - Template: "Restaurant Menu" (right side dropdown)
   - Publish

Step 5: View in Chrome
   - Click "View Page"
   - See your beautiful menu with photos and prices! ✅
